# 青途校园

青途校园是一个面向校园场景的移动端产品原型，用单页界面展示 AI 学习、技能接单与积分成长等设想，帮助快速体验产品的信息架构与视觉方向。

> 当前仓库内容为原型演示：AI、账户、资料上传及交易/接单等尚未接入；展示数据为示例，不会实际上传资料或处理交易。

## 原型展示

根目录 `index.html` 是青途校园主界面，采用移动端应用式布局。页面可切换首页、AI 学习、接单和个人中心等演示视图，并提供分类标签切换及提示反馈等交互。各页面中的对话、积分、订单、价格和个人资料均为演示内容，不代表真实服务或交易。

仓库还包含其他独立页面：

- `qingtu-app/index.html`、`template/index.html`：其他 HTML 页面入口。
- `personal-intro/index.html`：个人介绍与作品集页面。
- `luoxiaohei/index.html`：罗小黑主题的角色介绍与互动页面。
- `pet-world/index.html`：宠物主题页面。
- `cutovo/index.html`：Cutovo 赛博剪纸网页工具，配有独立的 `cutovo/app.js` 与 `cutovo/styles.css`。

这些页面是仓库中的独立静态页面，不应将其误认为青途校园主原型已集成的功能。

## 界面与交互

- 面向手机的应用式导航与分区布局，覆盖首页、AI 学习、接单和个人中心演示。
- 以卡片呈现 AI 学习入口、示例接单、积分信息和个人服务入口。
- AI 学习页展示拍照答疑、笔记整理、论文润色、模拟面试等功能设想，以及示例聊天内容。
- 接单页展示分类筛选、需求卡片、示例报价与接单/购买入口；相关交易流程尚未接入。
- 采用柔和马卡龙配色、圆角卡片和轻量交互反馈。

## 技术与目录

仓库以 HTML、CSS 和浏览器端 JavaScript 构成；青途校园主页面的样式与交互脚本以内嵌方式写在根目录 `index.html` 中。仓库未提供 Node/Python 等包管理清单或构建脚本。Cutovo 页面另有独立脚本和样式文件。

```text
.
├── index.html              # 青途校园主原型
├── qingtu-app/index.html   # 独立页面
├── template/index.html     # 独立页面
├── personal-intro/         # 个人介绍页面
├── luoxiaohei/             # 角色介绍互动页面
├── pet-world/              # 宠物主题页面
└── cutovo/                 # 赛博剪纸页面及其 JS/CSS
```

## 本地查看

无需安装项目依赖。可直接用现代浏览器打开根目录 `index.html` 查看主原型；也可分别打开上述子目录中的 `index.html` 查看对应页面。仓库包含 GitHub Pages 部署工作流配置，但本地打开不代表线上部署状态。

## 演示数据与使用边界

青途校园主页面明确标注为原型：AI、账户、资料上传及交易/接单尚未接入，页面数据为示例。请勿将演示对话、价格、积分、订单或个人资料当作真实业务数据。个人介绍页含有个人经历与介绍信息；发布或录屏前应由相关本人核对并授权。罗小黑页面注明为非官方角色介绍，相关角色及作品权利归原权利人。
